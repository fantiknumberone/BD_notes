## Сначала определяем столбцы, затем порядок

Одна строка результата здесь описывает тариф, абонента или событие. Перед запуском назови источник, выбранные поля и критерии сортировки. Дополнительный ключ после равных значений делает результат однозначным. Вычисляемый столбец не меняет сохранённые данные.

> [!info] Как решать
> На сайте введи SELECT и нажми «Проверить». При ошибке появятся эталон и его результат. Сравниваются значения и повторения строк; порядок важен, когда в эталоне есть ORDER BY. Данные каждой страницы запускаются заново; решения не меняют исходный дамп.

## Песочница: проверь свою гипотезу

```sql
-- run
SELECT plan_id, plan_name, monthly_fee FROM tariff_plans ORDER BY plan_id;
```

## Собери порядок рассуждения

```text
#order
Выбрать источник и поля
Задать порядок строк
Ограничить число строк
Проверить результат
```

## Запросы с автоматической проверкой

### 01. Поля тарифа

_База._

```text
#task
Выведи plan_id, plan_name, monthly_fee всех тарифов по plan_id.
= SELECT plan_id, plan_name, monthly_fee FROM tariff_plans ORDER BY plan_id;
```

> [!tip]- Подсказка после попытки
> Выбирай столбцы явно.

### 02. Список абонентов

_База._

```text
#task
Выведи subscriber_id, first_name, phone_number по subscriber_id.
= SELECT subscriber_id, first_name, phone_number FROM subscribers ORDER BY subscriber_id;
```

> [!tip]- Подсказка после попытки
> Не нужен SELECT \*.

### 03. Цена по убыванию

_База._

```text
#task
Выведи plan_name и monthly_fee: от дорогих к дешёвым, затем по plan_id.
= SELECT plan_name, monthly_fee FROM tariff_plans ORDER BY monthly_fee DESC, plan_id;
```

> [!tip]- Подсказка после попытки
> Основной и дополнительный критерии пишутся через запятую.

### 04. Разреши ничью

_Связи и условия._

```text
#task
Выведи subscriber_id, balance по balance DESC и subscriber_id ASC.
= SELECT subscriber_id, balance FROM subscribers ORDER BY balance DESC, subscriber_id;
```

> [!tip]- Подсказка после попытки
> Два абонента имеют одинаковые 100.

### 05. Псевдонимы

_Связи и условия._

```text
#task
Выведи plan_name как tariff, monthly_fee как fee, сортировка по plan_id.
= SELECT plan_name AS tariff, monthly_fee AS fee FROM tariff_plans ORDER BY plan_id;
```

> [!tip]- Подсказка после попытки
> AS меняет имя результата.

### 06. Цена за год

_Связи и условия._

```text
#task
Выведи plan_id и monthly_fee * 12 как annual_fee по plan_id.
= SELECT plan_id, monthly_fee * 12 AS annual_fee FROM tariff_plans ORDER BY plan_id;
```

> [!tip]- Подсказка после попытки
> Это арифметическое упражнение, не правило реального годового списания.

### 07. Секунды в минуты

_Самостоятельный разбор._

```text
#task
Для service_type_id = 1 выведи record_id и duration_seconds / 60.0 как minutes по record_id.
= SELECT record_id, duration_seconds / 60.0 AS minutes FROM call_records WHERE service_type_id = 1 ORDER BY record_id;
```

> [!tip]- Подсказка после попытки
> Отдели голосовые события от SMS.

### 08. Уникальные состояния

_Самостоятельный разбор._

```text
#task
Выведи уникальные status абонентов по status.
= SELECT DISTINCT status FROM subscribers ORDER BY status;
```

> [!tip]- Подсказка после попытки
> DISTINCT действует на весь выбранный набор полей.

### 09. Три максимальных баланса

_Самостоятельный разбор._

```text
#task
Выведи subscriber_id и balance трёх первых строк по balance DESC, subscriber_id ASC.
= SELECT subscriber_id, balance FROM subscribers ORDER BY balance DESC, subscriber_id LIMIT 3;
```

> [!tip]- Подсказка после попытки
> LIMIT применяется к уже заданному порядку результата.

### 10. Шаблон сортировки истории

_Самостоятельный разбор._

```text
#task
Выведи payment_id, payment_date, amount по payment_date DESC, payment_id DESC.
= SELECT payment_id, payment_date, amount FROM payments ORDER BY payment_date DESC, payment_id DESC;
```

> [!tip]- Подсказка после попытки
> Дополнительный ключ пригодится при одинаковом времени.

## Как проверить себя глубже

- [ ] Объяснил, что означает одна строка каждого результата.
- [ ] Предсказал хотя бы один результат до запуска.
- [ ] Объяснил роль NULL, повторений и сортировки в сложной задаче.
- [ ] Составил собственный вариант условия и проверил его в песочнице.
