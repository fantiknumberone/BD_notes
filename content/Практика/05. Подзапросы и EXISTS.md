## Вопрос «есть ли?» отличается от «сколько?»

EXISTS проверяет наличие подходящей строки и не размножает внешний результат. Подзапрос с MAX возвращает значение; сравнение с ним может найти несколько победителей. NOT EXISTS обычно яснее выражает отсутствие связи, чем NOT IN по полю с NULL.

> [!info] Как решать
> На сайте введи SELECT и нажми «Проверить». При ошибке появятся эталон и его результат. Сравниваются значения и повторения строк; порядок важен, когда в эталоне есть ORDER BY. Данные каждой страницы запускаются заново; решения не меняют исходный дамп.

## Песочница: проверь свою гипотезу

```sql
-- run
SELECT subscriber_id, first_name FROM subscribers AS s WHERE EXISTS (SELECT 1 FROM payments AS p WHERE p.subscriber_id=s.subscriber_id) ORDER BY subscriber_id;
```

## Собери порядок рассуждения

```text
#order
Выбрать кандидата во внешнем запросе
```

## Запросы с автоматической проверкой

### 01. Выше общего среднего

_База._

```text
#task
Выведи subscriber_id, balance с balance > среднего balance всех абонентов, по subscriber_id.
= SELECT subscriber_id, balance FROM subscribers WHERE balance > (SELECT AVG(balance) FROM subscribers) ORDER BY subscriber_id;
```

> [!tip]- Подсказка после попытки
> Подзапрос AVG возвращает одно значение.

### 02. Самые дорогие тарифы

_База._

```text
#task
Выведи plan_id, plan_name всех тарифов с максимальным monthly_fee по plan_id.
= SELECT plan_id, plan_name FROM tariff_plans WHERE monthly_fee = (SELECT MAX(monthly_fee) FROM tariff_plans) ORDER BY plan_id;
```

> [!tip]- Подсказка после попытки
> Сравнение с максимумом сохраняет возможную ничью.

### 03. Дорогой сегмент

_База._

```text
#task
Выведи subscriber_id абонентов тарифов с monthly_fee >= 800, по subscriber_id.
= SELECT subscriber_id FROM subscribers WHERE plan_id IN (SELECT plan_id FROM tariff_plans WHERE monthly_fee >= 800) ORDER BY subscriber_id;
```

> [!tip]- Подсказка после попытки
> Подзапрос возвращает набор ID, не цену.

### 04. Факт платежа

_База._

```text
#task
Выведи subscriber_id, first_name абонентов с хотя бы одним платежом, по subscriber_id.
= SELECT s.subscriber_id, s.first_name FROM subscribers AS s WHERE EXISTS (SELECT 1 FROM payments AS p WHERE p.subscriber_id = s.subscriber_id) ORDER BY s.subscriber_id;
```

> [!tip]- Подсказка после попытки
> Число совпадений справа не должно размножать абонента.

### 05. Полное отсутствие платежей

_Связи и условия._

```text
#task
Выведи subscriber_id абонентов без payments по subscriber_id.
= SELECT s.subscriber_id FROM subscribers AS s WHERE NOT EXISTS (SELECT 1 FROM payments AS p WHERE p.subscriber_id = s.subscriber_id) ORDER BY s.subscriber_id;
```

> [!tip]- Подсказка после попытки
> Это проверка отсутствия подходящей строки.

### 06. Есть платное событие

_Связи и условия._

```text
#task
Выведи subscriber_id с хотя бы одним call_records.cost > 0, по subscriber_id.
= SELECT s.subscriber_id FROM subscribers AS s WHERE EXISTS (SELECT 1 FROM call_records AS c WHERE c.subscriber_id = s.subscriber_id AND c.cost > 0) ORDER BY s.subscriber_id;
```

> [!tip]- Подсказка после попытки
> Не путай наличие события с положительной стоимостью.

### 07. Счёт без оплаты через EXISTS

_Связи и условия._

```text
#task
Выведи invoice_id счетов без связанного платежа по invoice_id.
= SELECT i.invoice_id FROM invoices AS i WHERE NOT EXISTS (SELECT 1 FROM payments AS p WHERE p.invoice_id = i.invoice_id) ORDER BY i.invoice_id;
```

> [!tip]- Подсказка после попытки
> NOT EXISTS не теряет смысл из-за NULL invoice\_id у свободного пополнения.

### 08. Выше среднего своего тарифа

_Связи и условия._

```text
#task
Для непустых plan_id выведи subscriber_id, balance, где баланс выше среднего абонентов того же тарифа. По subscriber_id.
= SELECT s.subscriber_id, s.balance FROM subscribers AS s WHERE s.plan_id IS NOT NULL AND s.balance > (SELECT AVG(other.balance) FROM subscribers AS other WHERE other.plan_id = s.plan_id) ORDER BY s.subscriber_id;
```

> [!tip]- Подсказка после попытки
> Среднее зависит от внешней строки.

### 09. Оплачивавшие без событий

_Самостоятельный разбор._

```text
#task
Выведи subscriber_id абонентов с платежом и без call_records, по subscriber_id.
= SELECT s.subscriber_id FROM subscribers AS s WHERE EXISTS (SELECT 1 FROM payments AS p WHERE p.subscriber_id = s.subscriber_id) AND NOT EXISTS (SELECT 1 FROM call_records AS c WHERE c.subscriber_id = s.subscriber_id) ORDER BY s.subscriber_id;
```

> [!tip]- Подсказка после попытки
> Соедини два логических факта, а не две таблицы сырых событий.

### 10. Тариф без активных

_Самостоятельный разбор._

```text
#task
Выведи plan_id, plan_name тарифов без абонентов status ACTIVE, по plan_id.
= SELECT t.plan_id, t.plan_name FROM tariff_plans AS t WHERE NOT EXISTS (SELECT 1 FROM subscribers AS s WHERE s.plan_id = t.plan_id AND s.status = 'ACTIVE') ORDER BY t.plan_id;
```

> [!tip]- Подсказка после попытки
> Отсутствие активных не означает отсутствие любых абонентов.

### 11. Предварительный итог

_Самостоятельный разбор._

```text
#task
Из подзапроса итогов payments выведи subscriber_id и paid_total > 100, по subscriber_id.
= SELECT p.subscriber_id, p.paid_total FROM (SELECT subscriber_id, SUM(amount) AS paid_total FROM payments GROUP BY subscriber_id) AS p WHERE p.paid_total > 100 ORDER BY p.subscriber_id;
```

> [!tip]- Подсказка после попытки
> У промежуточного результата собственная схема.

### 12. Каждый голосовой факт длиннее минуты

_Самостоятельный разбор._

```text
#task
Выведи subscriber_id тех, у кого есть исходящий звонок и нет исходящего с duration_seconds <= 60, по subscriber_id.
= SELECT s.subscriber_id FROM subscribers AS s WHERE EXISTS (SELECT 1 FROM call_records AS c WHERE c.subscriber_id = s.subscriber_id AND c.service_type_id = 1) AND NOT EXISTS (SELECT 1 FROM call_records AS c WHERE c.subscriber_id = s.subscriber_id AND c.service_type_id = 1 AND c.duration_seconds <= 60) ORDER BY s.subscriber_id;
```

> [!tip]- Подсказка после попытки
> Дополнительный EXISTS исключает пустой набор звонков.
