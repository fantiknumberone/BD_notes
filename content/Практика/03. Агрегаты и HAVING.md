## Выбери единицу группировки

Если строка отчёта означает один тариф, GROUP BY должен задавать тариф. COUNT(\*) считает строки, COUNT(email) — известные email. WHERE отбирает исходные строки, HAVING — уже рассчитанные группы. Для суммы по пустому набору продумай COALESCE.

> [!info] Как решать
> На сайте введи SELECT и нажми «Проверить». При ошибке появятся эталон и его результат. Сравниваются значения и повторения строк; порядок важен, когда в эталоне есть ORDER BY. Данные каждой страницы запускаются заново; решения не меняют исходный дамп.

## Запросы с автоматической проверкой

### 01. Строки и заполненные значения

_База._

```text
#task
Верни subscriber_count = COUNT(*) и email_count = COUNT(email) одной строкой.
= SELECT COUNT(*) AS subscriber_count, COUNT(email) AS email_count FROM subscribers;
```

> [!tip]- Подсказка после попытки
> COUNT(column) пропускает NULL.

### 02. Общая сумма платежей

_База._

```text
#task
Верни payments_count и paid_total по payments.
= SELECT COUNT(*) AS payments_count, SUM(amount) AS paid_total FROM payments;
```

> [!tip]- Подсказка после попытки
> Считай факты платежей, не уникальные суммы.

### 03. Абоненты на тарифе

_База._

```text
#task
Для непустых plan_id выведи plan_id, subscriber_count по plan_id.
= SELECT plan_id, COUNT(*) AS subscriber_count FROM subscribers WHERE plan_id IS NOT NULL GROUP BY plan_id ORDER BY plan_id;
```

> [!tip]- Подсказка после попытки
> Сначала отбери исходные строки.

### 04. Несколько абонентов

_База._

```text
#task
Выведи plan_id, subscriber_count только у непустых тарифов с COUNT(*) > 1 по plan_id.
= SELECT plan_id, COUNT(*) AS subscriber_count FROM subscribers WHERE plan_id IS NOT NULL GROUP BY plan_id HAVING COUNT(*) > 1 ORDER BY plan_id;
```

> [!tip]- Подсказка после попытки
> Условие по агрегату относится к HAVING.

### 05. Сумма событий

_Связи и условия._

```text
#task
Из call_records выведи subscriber_id, total_cost = SUM(cost) по subscriber_id.
= SELECT subscriber_id, SUM(cost) AS total_cost FROM call_records GROUP BY subscriber_id ORDER BY subscriber_id;
```

> [!tip]- Подсказка после попытки
> Сюда входят все типы событий таблицы.

### 06. Длительность голосовых событий

_Связи и условия._

```text
#task
Для service_type_id = 1 выведи subscriber_id, total_seconds по subscriber_id.
= SELECT subscriber_id, SUM(duration_seconds) AS total_seconds FROM call_records WHERE service_type_id = 1 GROUP BY subscriber_id ORDER BY subscriber_id;
```

> [!tip]- Подсказка после попытки
> Фильтрация делается до группировки.

### 07. Статистика по статусу

_Связи и условия._

```text
#task
Выведи status, subscriber_count, average_balance по status.
= SELECT status, COUNT(*) AS subscriber_count, AVG(balance) AS average_balance FROM subscribers GROUP BY status ORDER BY status;
```

> [!tip]- Подсказка после попытки
> Не добавляй имя отдельного абонента к строке группового итога.

### 08. Объём трафика

_Связи и условия._

```text
#task
Выведи subscriber_id, total_mb = SUM(data_mb) из data_usage по subscriber_id.
= SELECT subscriber_id, SUM(data_mb) AS total_mb FROM data_usage GROUP BY subscriber_id ORDER BY subscriber_id;
```

> [!tip]- Подсказка после попытки
> Единица результата остаётся MB.

### 09. Порог событийных расходов

_Самостоятельный разбор._

```text
#task
Выведи subscriber_id, total_cost из call_records, где SUM(cost) > 5, по subscriber_id.
= SELECT subscriber_id, SUM(cost) AS total_cost FROM call_records GROUP BY subscriber_id HAVING SUM(cost) > 5 ORDER BY subscriber_id;
```

> [!tip]- Подсказка после попытки
> Не заменяй сумму фильтром cost > 5.

### 10. Границы тарифных цен

_Самостоятельный разбор._

```text
#task
Верни min_fee, max_fee и average_fee по tariff_plans.
= SELECT MIN(monthly_fee) AS min_fee, MAX(monthly_fee) AS max_fee, AVG(monthly_fee) AS average_fee FROM tariff_plans;
```

> [!tip]- Подсказка после попытки
> Разные агрегаты могут находиться в одной строке.

### 11. Число реально использованных тарифов

_Самостоятельный разбор._

```text
#task
Верни used_plan_count как COUNT(DISTINCT plan_id) из subscribers.
= SELECT COUNT(DISTINCT plan_id) AS used_plan_count FROM subscribers;
```

> [!tip]- Подсказка после попытки
> NULL не считается отдельным известным ID в COUNT(column).

### 12. Число должников по статусу

_Самостоятельный разбор._

```text
#task
Выведи status, debtor_count только по строкам balance < 0, сортировка status.
= SELECT status, COUNT(*) AS debtor_count FROM subscribers WHERE balance < 0 GROUP BY status ORDER BY status;
```

> [!tip]- Подсказка после попытки
> Это группы отфильтрованных должников, не всех абонентов.

## Как проверить себя глубже

- [ ] Предсказал хотя бы один результат до запуска.
- [ ] Объяснил роль NULL, повторений и сортировки в сложной задаче.
- [ ] Составил собственный вариант условия и проверил его в песочнице.
